دستیار کیشایی - PWA
1) فایل ZIP را Extract کن.
2) برای نصب به‌صورت اپ، فایل‌ها باید روی یک HTTPS website قرار بگیرند؛ باز کردن مستقیم index.html از فایل‌منیجر معمولاً نصب PWA را فعال نمی‌کند.
3) بعد از باز کردن سایت در Chrome: منوی سه‌نقطه > Install app / افزودن به صفحه اصلی.
این نسخه برای تست رابط کاربری است و هنوز AI واقعی، OTP و Firebase آنلاین را فعال نکرده است.
